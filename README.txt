HYRSPACE v3 — профили + роли + социальная лента

1. Создай/открой проект Supabase.
2. Если это новая версия сайта, выполни supabase.sql целиком.
3. В Authentication -> Providers -> Email можно оставить Confirm Email выключенным для разработки.
4. Скопируй Project URL и Publishable key в config.js.
5. Запускай сайт через Live Server/localhost.
6. Зарегистрируй несколько аккаунтов.
7. В «Мой профиль» можно поставить аватар по URL, текст «О себе» и одну из визуальных ролей:
   Пользователь, VIP, Мем Года, Администратор.
8. «Люди» показывает всех зарегистрированных пользователей.
9. «Лента» позволяет писать посты. Под каждым постом есть отдельные комментарии.
10. Публичный профиль пользователя показывает его посты и профильные данные.

Безопасность:
Роль в этой версии выбирается самим пользователем и является декоративной.
Нельзя использовать её как реальное право администратора. Настоящие права модерации нужно делать server-side
через отдельную таблицу/claims/policies.

Не вставляй service_role key в браузер.
